# YouTube Thumbnail Üretici

Tek dosyalık, ücretsiz, tarayıcıda çalışan YouTube thumbnail aracı (1280×720 PNG).

## Kullanım
`index.html` dosyasını tarayıcıda aç. Kurulum gerekmez.

- Başlık, yazı tipi, boyut, renkler ve konumu ayarla
- İstersen arka plan resmi ve ön plan (yüz/ürün) resmi ekle
- **PNG indir** ile kaydet

Satır başı için başlık kutusunda Enter kullan.
